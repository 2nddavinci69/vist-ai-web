# VIST-AI FORENSIC REPORT GENERATOR

## 1. Purpose
The VIST-AI Forensic Report Generator defines the structure and content of the final report produced from a completed evaluation[cite: 65]. The report converts documented test evidence into a structured, traceable, and professionally reviewable document[cite: 65].

## 2. Core Report Structure
A complete VIST-AI forensic report follows a rigorous 20-point structure including[cite: 87]:
1. Cover Page[cite: 86]
2. Executive Summary[cite: 86]
3. System Under Evaluation[cite: 86]
4. Evaluation Objective[cite: 86]
5. Test Methodology[cite: 86]
6. Stimulus Description[cite: 86]
7. Test Conditions[cite: 86]
8. Evidence Summary[cite: 86]
9. Model Response Analysis[cite: 86]
10. VIST-AI Metrics[cite: 86]
11. Failure Signatures[cite: 86]
12. Forensic Findings[cite: 86]
13. Reproducibility Analysis[cite: 86]
14. Limitations[cite: 86]
15. Recommendations[cite: 86]
16. Evidence Traceability[cite: 86]
17. Appendix[cite: 86]
18. Evidence Manifest[cite: 86]

## 3. Evidence-Based Reporting Principles
* The report must strictly distinguish between observed evidence, analyst observations, analytical interpretation, and final findings[cite: 65].
* Findings must remain proportional to the available evidence without making unverified claims about internal model architectures[cite: 90].
