# VIST-AI: Visual Invariant Stress Test

## Overview
VIST-AI is an independent forensic evaluation framework designed to audit multimodal AI systems for visual grounding, geometric robustness, and confabulation behaviors under controlled stress conditions.

## Directory Structure
- `docs/`: Core documentation and methodology files (01 to 08).
- `tests/cases/`: Standardized JSON test cases (e.g., VIST-2026-0001).
- `evidence/`: Preserved visual stimuli, ground truth, and model responses.
- `reports/`: Generated forensic evaluation reports.

## Core Evaluation Dimensions
1. Visual Grounding
2. Geometric Robustness
3. Confabulation Behavior
4. Uncertainty Acknowledgment
5. Reproducibility
